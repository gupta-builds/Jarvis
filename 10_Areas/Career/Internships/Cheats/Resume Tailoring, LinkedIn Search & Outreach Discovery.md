# Resume Tailoring Research
Use this as a worksheet for turning a job description into a short list of evidence to lead with.
## Extract requirements
==Mark the posting’s required skills and tasks before considering its nice-to-haves.==
For a posting asking for API work, put the API requirement in one column and the strongest approved API bullet in another.
## Test the rewrite
==Keep the task, ownership and result intact when you mirror the posting’s vocabulary.==
If there is no matching evidence, mark it as a gap. Use the [[20_Progress/Internship/Resumes/Resume Guide|Resume Guide]] when ordering and exporting the draft.
