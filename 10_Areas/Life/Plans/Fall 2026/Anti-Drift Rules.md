# Anti-Drift Rules — Fall 2026

The named failure mode, verified 2026-09-15: **writing the plan counts as doing the plan**. The Fall 2026 Plan, One Thing, Builds, and Courses Board all got a real rebuild 2026-09-07 through 09-10 — genuinely good documents. Then the daily note went silent for 7 straight days (last one: 2026-09-08), the week 1 One Hard Thing (`Main Cover Letter.md`) never got finished, and every one of the six Fall classes has zero Week-2 content despite classes already meeting twice. The strategy layer moved; the execution layer didn't. That's the specific drift these rules exist to catch — not generic distraction.

## The core rules

1. **A plan edit is not a day's work.** Rewriting `Fall 2026 Plan.md`, a course Board, or any MOC does not substitute for today's Fall Daily Floor (application move, LeetCode/CodePath, class step). If the day's only output was a note about the system, that's a RED day regardless of how good the note is.
2. **No platform archaeology this session or in daily ops.** No choosing MCPs, editing `.mcp.json`, comparing AI tools, "optimizing the stack." Tool work is allowed only as an explicit, time-boxed weekly slot — never mid-task.
3. **The named blocker gets finished before its neighbors get attention.** Right now that's `Main Cover Letter.md` — nothing else in the internship track is worth touching until it exists and one application has actually moved `Current/` → `Applied/`.
4. **Never Miss Twice.** Missing one `/startday`/`/closeday` is data. Missing two in a row is the trigger to stop and ask what actually broke, not to push through on memory. Per the Fall 2026 Plan's own Update Protocol, two missed `/weekly-review` runs forces a full re-scope conversation.
5. **One tab, one task.** When a tab-switch toward setup/optimization/new-agent-authoring happens mid-task, that's the cue to return to today's note.

## The "Do NOT do today" list (goes in every Today note)

- MCP / connector setup or comparison
- New agents / new skills authoring
- GitHub repo stars triage
- AI platform comparison / stack optimization
- `.obsidian` / plugin configuration
- Rewriting a plan document instead of running it

If the urge hits, it goes to the parking lot, not the day.
