## Key ideas (short)
- **PCA's real failure mode:** it fails when the direction of largest variance isn't the direction that matters for the actual labels/question — normalizing mismatched-unit features first is the fix when units genuinely differ, but not when features are already comparable (e.g. word counts, tf-idf).
- **k-means' real failure modes:** anisotropic (stretched/rotated) clusters, clusters of different densities, non-linear cluster boundaries, and overlapping clusters — each a case where "nearest centroid by Euclidean distance" stops matching the true group structure.
- **LDA as Bayes classification under an assumption:** assumes every class's features follow a Gaussian with a *shared* covariance matrix across classes; this reduces Bayes-optimal classification to a *linear* decision rule in $x$ — which is "LDA" is named for being linear, not for any other reason.
- **QDA relaxes LDA's one assumption:** separate covariance per class → quadratic decision rule, more flexible, more parameters, more variance.
- **GMM = k-means + covariance, via Expectation-Maximization:** compute each cluster's mean *and* covariance, assign points by Gaussian likelihood rather than raw distance — this lets GMM handle anisotropic and overlapping clusters that break k-means, at the cost of also only reaching a local optimum.

### 1. LEC 3.1 — Advanced Clustering, LDA, GMM (Tue 10/20)
	Opens as the Unit 3 title slide ("Regression and advanced clustering"), previewing the unit's full scope: improved clustering/dimensionality reduction, supervised dimensionality reduction, Gaussian Mixture Models, DBSCAN ("maybe"), regression with PyTorch, and backpropagation — today's actual content is only the clustering/GMM portion.
	States PCA's and k-means' shortcomings directly: PCA assumes all features share comparable units (normalize first, unless features are already naturally comparable like word counts/tf-idf) and fails when the variance-maximizing direction isn't meaningful for the labels; k-means fails on anisotropic, differently-dense, non-linearly-separable, or overlapping clusters. Poses the two sketch-activities named in Examples worth keeping.
	Introduces LDA as the supervised fix to PCA's label-blindness: assumes all class labels' features follow Gaussian distributions with *different means but the same covariance matrix*. Reviews the covariance-matrix mechanics needed first: 1-D variance $E[(X-E[X])^2]$; the multivariate extension (covariance between two variables, $E[(X-E[X])(Y-E[Y])]-$style), and the full $p\times p$ sample covariance matrix $Q$ (symmetric, positive definite) built from a data matrix $X$.
	Derives the LDA classification rule directly from Bayes classification: maximize $c(x_0)=\arg\max_j \Pr(Y=j\mid X=x_0)$ under the shared-covariance-Gaussian assumption, which reduces to maximizing a function of $x_0$, the class sample mean $\mu_j$, the class proportion $\pi_j$, and the shared sample covariance $Q$ — stated directly to produce a *linear* decision boundary between classes.
	Contrasts PCA vs. LDA explicitly (see Examples worth keeping), then introduces QDA as LDA with a separate covariance matrix per class — "quadratic" because the resulting decision function is now quadratic in $x$ — with the direct textbook citation to §4.4.3 and the 60%-accuracy stock-market result in §4.7.4.
	Transitions to the unsupervised analogue: "we can use what we just learned to predict gaussian distributions in unlabeled data" — extending k-means to also track each cluster's covariance, assigning points by maximum likelihood rather than raw distance to centroid. Names this the Gaussian Mixture Model, equivalently Expectation-Maximization (EM): (1) choose $k$; (2) randomly assign points to clusters; (3) iterate — fit each cluster's sample mean/covariance (the "E" step's Gaussian fit), then reassign each point to its most probable Gaussian (the "M" step) — until convergence, with the same local-optimum caveat as k-means.
	States GMM's two statistical-learning roles directly: (1) clustering — a generalization of k-means allowing anisotropic clusters, soft/overlapping partitions, solved via EM; (2) density estimation — estimating the data's probability density as a weighted sum of the fitted Gaussians, also via EM. Demonstrates on the "Mickey Mouse" (differently-sized clusters) and "overlapping distributions" synthetic datasets, both cases where k-means struggles and GMM succeeds.
	Closes with a direct side-by-side summary table (K-means: linear boundaries, isotropic, hard partitions, fixed cluster count; GMM: covariance-informed, anisotropic/spherical, handles overlap, gives relative cluster-membership probability — and the PCA/LDA summary already described above), plus a one-line closing note that all these methods benefit from data normalization.

## Lecture-to-textbook synthesis
==LDA and GMM solve the same underlying problem — "classify or group points by fitting Gaussian distributions" — but LDA assumes a single shared covariance across *known* classes while GMM fits a separate covariance per *unknown* cluster via Expectation-Maximization, and that one difference (known labels, shared covariance vs. unknown labels, per-cluster covariance) is the entire conceptual distance between a supervised and an unsupervised method here.==
*Mechanism:* both methods place a Gaussian density over each group and classify/assign a point to the group under which it's most probable; LDA's Bayes-rule derivation (given labels) collapses to a linear decision boundary because the shared covariance cancels the quadratic term when comparing any two classes; GMM's EM iteration (no labels) instead re-estimates each cluster's own mean *and* covariance every iteration, so the decision boundary between any two components can be genuinely non-linear (anisotropic) once their covariances differ.
- Lecture example/scenario: the deck's own "Mickey Mouse" synthetic dataset (clusters of different sizes) and overlapping-distributions dataset are the direct unsupervised analogue of ISL's QDA-vs-LDA figure (quadratic boundary needed when per-class covariance genuinely differs) — same underlying reason (shared vs. separate covariance), applied to clustering instead of classification.
- Textbook connection: [[20_Progress/Degree/CSCI 4521/Textbook/ISL/Chapter - 4|ISL Chapter 4]]'s §4.4.3 QDA-vs-LDA trade-off is the supervised mirror of this week's k-means-vs-GMM trade-off — in both cases, assuming one shared covariance buys a simpler (linear) boundary and lower variance, while allowing per-group covariance buys flexibility at a real parameter-count cost.

> [!WARNING]
> Treating GMM as "just k-means with extra steps" rather than noticing the actual mechanism change — GMM assigns points by Gaussian likelihood (a genuinely different rule from nearest-centroid-by-distance), which is exactly what lets it handle anisotropic and overlapping clusters k-means cannot.

> Week 7 extends both of Week 6's unsupervised methods into forms that model covariance explicitly: LDA/QDA for supervised classification (known labels, Gaussian-per-class) and GMM for unsupervised clustering (unknown labels, Gaussian-per-cluster via EM) — the shared thread is that assuming one covariance for everything buys simplicity, and assuming a separate covariance per group buys flexibility at a real cost.
