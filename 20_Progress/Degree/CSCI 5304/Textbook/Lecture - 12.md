## Chapter Summary
==Conditioning is a property of a *problem*, not an algorithm: a well-conditioned problem keeps small input perturbations small in the output, while an ill-conditioned one can blow a tiny input change up into a large output change, regardless of how good the algorithm solving it is.== *Mechanism:* model a problem as a function $f:X\to Y$ between normed spaces; the absolute condition number $\hat\kappa=\sup_{\delta x}\|\delta f\|/\|\delta x\|$ measures worst-case output sensitivity, and the relative condition number $\kappa$ rescales both sides by $\|f(x)\|$ and $\|x\|$ - for differentiable $f$, both reduce to norms of the Jacobian. Applied to matrices, this yields $\kappa(A)=\|A\|\|A^{-1}\|=\sigma_1/\sigma_m$ in the 2-norm, the single number that governs how many digits of accuracy are lost solving $Ax=b$.
## Key Concepts
- **Well-/ill-conditioned problem (instance)** (p. 89-90): a problem $f$ at $x$ is well-conditioned if all small perturbations of $x$ cause only small changes in $f(x)$; ill-conditioned if some small perturbation causes a large change. "Small"/"large" depend on absolute or relative scale.
- **Absolute condition number** $\hat\kappa=\lim_{\delta\to0}\sup_{\|\delta x\|\le\delta}\|\delta f\|/\|\delta x\|$ (p. 90, eq. 12.1-12.3): for differentiable $f$, $\hat\kappa=\|J(x)\|$, the induced norm of the Jacobian.
- **Relative condition number** $\kappa=\sup_{\delta x}\big(\|\delta f\|/\|f(x)\|\big)/\big(\|\delta x\|/\|x\|\big)$ (p. 91, eq. 12.4-12.6): for differentiable $f$, $\kappa=\|J(x)\|/(\|f(x)\|/\|x\|)$. More important in numerical analysis than $\hat\kappa$ because floating-point arithmetic introduces *relative* errors (Lecture 13). Well-conditioned if $\kappa$ is small (1, 10, $10^2$); ill-conditioned if large ($10^6$, $10^{16}$).
- **Condition of matrix-vector multiplication** (p. 93-94, eq. 12.9-12.14): computing $Ax$ from $x$ has $\kappa=\|A\|\,\|x\|/\|Ax\|\le\|A\|\|A^{-1}\|$ for square nonsingular $A$ (Theorem 12.1); the same bound governs computing $b$ from $x$ or $x$ from $b$ in $Ax=b$, with equality exactly when $x$/$b$ aligns with the extreme singular vectors.
- **Condition number of a matrix** $\kappa(A)=\|A\|\|A^{-1}\|$ (p. 94-95, eq. 12.15-12.17): in the 2-norm, $\kappa(A)=\sigma_1/\sigma_m$ - the eccentricity of the hyperellipse $A$ maps the unit sphere to. For rectangular full-rank $A$, $\kappa(A)=\|A\|\|A^+\|=\sigma_1/\sigma_n$.
- **Condition of a system of equations** (p. 95-96, Theorem 12.2): perturbing $A$ itself (holding $b$ fixed) in $x=A^{-1}b$ also has condition number exactly $\kappa(A)$ - the same single number governs sensitivity to perturbing $x$, $b$, or $A$. Solving an ill-conditioned system costs "$\log_{10}\kappa(A)$ digits" of accuracy.
## Full Reading Notes
### Condition of a Problem (p. 89-90)
A problem is a function $f:X\to Y$ between normed vector spaces, usually nonlinear but continuous; a *problem instance* fixes a particular data point $x$. Well-/ill-conditioned is defined at that instance, and "small"/"large" is scale-dependent - sometimes absolute, sometimes relative.
### Absolute Condition Number (p. 90)
$\hat\kappa=\lim_{\delta\to0}\sup_{\|\delta x\|\le\delta}\|\delta f\|/\|\delta x\|$ (eq. 12.1), written informally as a supremum over infinitesimal $\delta x$ (eq. 12.2). For differentiable $f$ with Jacobian $J(x)$ ($J_{ij}=\partial f_i/\partial x_j$), $\delta f\approx J(x)\delta x$ to first order, giving $\hat\kappa=\|J(x)\|$ (eq. 12.3) in the norm induced by $X,Y$'s norms.
### Relative Condition Number (p. 91)
$\kappa=\lim_{\delta\to0}\sup_{\|\delta x\|\le\delta}\big(\|\delta f\|/\|f(x)\|\big)\big/\big(\|\delta x\|/\|x\|\big)$ (eq. 12.4-12.5); for differentiable $f$, $\kappa=\|J(x)\|/(\|f(x)\|/\|x\|)$ (eq. 12.6). The book states directly that relative condition numbers matter more in numerical analysis because floating-point arithmetic's errors are relative, not absolute (next lecture).
### Examples (p. 91-93)
Six worked examples, each computing $\kappa$ directly from the Jacobian: **12.1** $f(x)=x/2$, $\kappa=1$ (well-conditioned); **12.2** $f(x)=\sqrt x$, $\kappa=1/2$ (well-conditioned); **12.3** $f(x)=x_1-x_2$ (using the $\infty$-norm), $\kappa=2/(|x_1-x_2|/\max\{|x_1|,|x_2|\})\to\infty$ as $x_1\to x_2$ - the formal statement of "cancellation error"; **12.4** $f(x)=\tan x$ near $x=10^{100}$ - effectively uncomputable, referencing Feynman's "Lucky Numbers" story; **12.5** polynomial rootfinding is classically ill-conditioned (double root of $(x-1)^2$ becomes two real roots $0.99,1.01$ under a tiny coefficient perturbation; the Wilkinson polynomial $\prod_{i=1}^{20}(x-i)$ has $\kappa\approx5.1\times10^{13}$ for its most sensitive root, $x=15$); **12.6** nonsymmetric-matrix eigenvalues can be wildly ill-conditioned (two matrices differing by $0.001$ in one entry have eigenvalue sets $\{1,1\}$ vs. $\{0,2\}$), while symmetric/normal matrices have $\hat\kappa=1$ for their eigenvalues (Exercise 26.3).
### Condition of Matrix-Vector Multiplication (p. 93-94)
Fixing $A$, perturbing $x$: $\kappa=\|A\|\|x\|/\|Ax\|$ exactly (eq. 12.9); if $A$ is square nonsingular, $\|x\|/\|Ax\|\le\|A^{-1}\|$ loosens this to $\kappa\le\|A\|\|A^{-1}\|$ (eq. 12.10), with equality exactly when $x$ is a multiple of $A$'s minimal right singular vector. Extends to full-rank rectangular $A$ via the pseudoinverse $A^+$. **Theorem 12.1**: computing $b$ from $x$ in $Ax=b$ has $\kappa=\|A\|\|x\|/\|b\|\le\|A\|\|A^{-1}\|$ (eq. 12.13, equality when $x$ aligns with the minimal singular vector); computing $x$ from $b$ has $\kappa=\|A^{-1}\|\|b\|/\|x\|\le\|A\|\|A^{-1}\|$ (eq. 12.14, equality when $b$ aligns with the maximal singular vector).
### Condition Number of a Matrix (p. 94-95)
$\kappa(A)=\|A\|\|A^{-1}\|$ (eq. 12.15) - a property of the matrix itself, not a specific problem instance. In the 2-norm, $\|A\|_2=\sigma_1$, $\|A^{-1}\|_2=1/\sigma_m$, so $\kappa(A)=\sigma_1/\sigma_m$ (eq. 12.16), geometrically the eccentricity of the image hyperellipse. For rectangular full-rank $A\in\mathbb C^{m\times n}$, $\kappa(A)=\|A\|\|A^+\|=\sigma_1/\sigma_n$ (eq. 12.17).
### Condition of a System of Equations (p. 95-96)
Now perturb $A$ itself, holding $b$ fixed: $(A+\delta A)(x+\delta x)=b$ with $Ax=b$ and dropping the second-order term gives $\delta x=-A^{-1}(\delta A)x$, so $\big(\|\delta x\|/\|x\|\big)/\big(\|\delta A\|/\|A\|\big)\le\|A^{-1}\|\|A\|=\kappa(A)$, with equality achievable for suitable $\delta A$ (dual-norm argument, Exercise 3.6). **Theorem 12.2** states this exactly: the condition number of $x=A^{-1}b$ with respect to perturbations in $A$ is $\kappa(A)$ itself. The chapter closes on the headline consequence: solving $Ax=b$ with an ill-conditioned $A$ costs "$\log_{10}\kappa(A)$ digits" of accuracy, independent of which algorithm is used.

## Worked Example
The live $f(x_1,x_2)=x_1-x_2$ example, solved on the board with the $\infty$-norm exactly as in the book's Example 12.3: Jacobian $J=[1\ -1]$, $\|J\|_\infty=2$, giving $\kappa=2/\big(|x_1-x_2|/\max\{|x_1|,|x_2|\}\big)$ - the professor connected this directly to "when you subtract two numbers that are very similar in floating-point arithmetic, the error can be almost unbounded," the same cancellation-error moral the book draws from this same example. A second live numeric illustration (not in the book, but matching its spirit): if $\kappa\sim10^{10}$ and machine epsilon $\sim10^{-16}$, the resulting error is $\sim10^{-6}$ - "only six digits of accuracy" from a problem that looks perfectly reasonable to state, used to motivate why real ill-conditioned problems (the book's Wilkinson-polynomial and nonsymmetric-eigenvalue examples) are a genuine practical concern, not a pathological curiosity.
