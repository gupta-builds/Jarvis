## Chapter Summary
==A matrix is unitary exactly when its columns are an orthonormal set, and multiplying by a unitary matrix never changes length or angle - it only rotates or reflects.== *Mechanism:* the inner product $x^*y$ is the algebraic quantity behind both length ($\|x\|^2 = x^*x$) and angle ($\cos\alpha = x^*y/\|x\|\|y\|$, p. 12); a unitary $Q$ satisfies $Q^*Q = I$, so $(Qx)^*(Qy) = x^*Q^*Qy = x^*y$ exactly (p. 14) - the inner product, and therefore every length and angle built from it, survives the transformation untouched. Norms generalize "length" itself beyond the Euclidean case, and the **induced matrix norm** (p. 18-19) extends that idea to matrices: how much can $A$ stretch a vector, relative to how big the vector started.
## Key Concepts
### From Lecture 2 (orthogonality)
- **Adjoint ($x^*$)**: the conjugate transpose of a vector or matrix (p. 11) - for real vectors this is the ordinary **transpose**, and the professor's own framing for this course (which stays real throughout) collapses $A^*$ to $A^T$ everywhere.
- **Hermitian matrix**: $A = A^*$ (p. 11); for a real matrix this is called **symmetric** ($A = A^T$).
- **Inner product ($x^*y$)**: $\sum_i \bar{x}_i y_i$ (p. 12, eq. 2.1) - simultaneously an algebraic quantity and a length/angle measurement.
- **Orthogonality**: $x^*y = 0$ (p. 13); a set is **orthogonal** if pairwise orthogonal, **orthonormal** if additionally every vector has unit length.
- **Theorem 2.1** (p. 13): an orthogonal set of nonzero vectors is automatically linearly independent - proved by assuming a dependency and showing it forces $\|v_k\|^2 = 0$, contradicting $v_k \neq 0$. Corollary: $m$ orthogonal vectors in $\mathbb{C}^m$ form a basis.
- **Unitary matrix ($Q$)**: square with $Q^*Q = I$ (p. 14), equivalently columns form an orthonormal basis; the real-matrix name is **orthogonal matrix**.
### From Lecture 3 (norms)
- **Norm**: a function satisfying positivity, the triangle inequality, and absolute homogeneity (p. 17, eq. 3.1). "The norm" without qualification means the 2-norm.
- **$p$-norm**: $\|x\|_p = (\sum_i |x_i|^p)^{1/p}$ (p. 18, eq. 3.2), unifying the 1-norm, 2-norm, and (in the limit) the $\infty$-norm $= \max_i|x_i|$.
- **Weighted norm**: $\|x\|_W = \|Wx\|$ for diagonal (or more generally nonsingular) $W$ (p. 18, eq. 3.3).
- **Induced matrix norm**: $\|A\|_{(m,n)} = \sup_{x\neq 0} \|Ax\|_{(m)}/\|x\|_{(n)}$ (p. 19, eq. 3.6) - the matrix-level analogue of a vector norm, defined via its action as an operator.
- **Frobenius norm**: $\|A\|_F = (\sum_{i,j}|a_{ij}|^2)^{1/2} = \sqrt{\operatorname{tr}(A^*A)}$ (p. 22-23, eq. 3.16-3.18) - the one important matrix norm *not* induced by a vector norm.
## Full Reading Notes
### Adjoint (p. 11)
The complex conjugate of a scalar negates its imaginary part; for real scalars it does nothing. The adjoint $A^*$ of an $m\times n$ matrix is the $n\times m$ matrix whose $(i,j)$ entry is the conjugate of $A$'s $(j,i)$ entry. $(AB)^* = B^*A^*$ (eq. 2.4), the adjoint analogue of $(AB)^{-1} = B^{-1}A^{-1}$ (eq. 2.5); this pairing is used constantly in later proofs (e.g. Lecture 5's existence proof manipulates $U_1^*AV_1$ using exactly this rule). The book's own convention is to write $A^*$ throughout, even for real matrices, rather than $A^T$ - "the reader who prefers to imagine that all quantities are real and that $*$ is a synonym for $^T$ will rarely get into trouble" (p. 12).
### Inner product and the geometric picture (p. 12)
$x^*y = \sum_i \bar{x}_i y_i$ (eq. 2.1); length $\|x\| = \sqrt{x^*x}$ (eq. 2.2); angle $\cos\alpha = x^*y / \|x\|\|y\|$ (eq. 2.3). The book is explicit that the geometric interpretation (angle, length) assumes real vectors, though it usually carries over to the complex case too. The inner product is **bilinear** - linear in each argument separately (p. 12) - a property used immediately in the orthogonal-decomposition argument below. *Lecture:* the professor derived the same $x^*y = \|x\|\|y\|\cos\alpha$ fact independently via the law of cosines, reaching the identical formula from a different starting point - worth noting as a real example of the textbook and the lecture arriving at the same result by different routes, matching the Lecture-to-textbook synthesis convention of flagging where sources differ in approach even when they agree in conclusion.
### Orthogonal vectors and Theorem 2.1 (p. 13)
Two vectors are **orthogonal** if $x^*y=0$. Theorem 2.1: vectors in an orthogonal set are linearly independent. *Worked proof (p. 13):* suppose some $v_k$ in orthogonal set $S$ is dependent, $v_k = \sum_{i\neq k} c_i v_i$. Since $v_k \neq 0$, $v_k^*v_k = \|v_k\|^2 > 0$. But computing $v_k^*v_k$ by substituting the dependency and using bilinearity plus orthogonality collapses every term to zero - contradiction. Corollary: an orthogonal set of $m$ vectors in $\mathbb{C}^m$ is automatically a basis - this is exactly the fact the lecture used to argue a unitary matrix is automatically full rank, tying back to Lecture 1's full-rank-$\Leftrightarrow$-one-to-one theorem.
### Components of a vector (p. 13-14)
Given an orthonormal set $\{q_1,\ldots,q_n\}$ and arbitrary $v$, the vector $r = v - \sum_i (q_i^*v)q_i$ (eq. 2.6) is orthogonal to every $q_i$ - verified directly by computing $q_i^*r$ and watching the sum collapse via orthonormality (p. 13). This gives the decomposition $v = r + \sum_i(q_i^*v)q_i = r + \sum_i(q_iq_i^*)v$ (eq. 2.7-2.8), stated in two equivalent forms: $v$ as a sum of **coefficients** $q_i^*v$ times basis vectors, or $v$ as a sum of **orthogonal projections** $(q_iq_i^*)v$ onto each direction. The rank-one matrix $q_iq_i^*$ performing each projection is exactly the object [[20_Progress/Degree/CSCI 5304/Textbook/Lecture - 6|Lecture 6]] builds a whole theory around (the book flags this forward-link explicitly, p. 13: "We shall discuss this and other projection processes in Lecture 6").
### Unitary matrices and multiplication by one (p. 14-15)
$Q^*Q = I$ (equivalently $Q^* = Q^{-1}$); columnwise this reads $q_i^*q_j = \delta_{ij}$ (p. 14). *Interpretation carried over from Lecture 1:* $Qx$ is the linear combination of $Q$'s columns weighted by $x$; conversely $Q^*b$ is the coefficient vector of $b$'s expansion in $Q$'s own column basis (p. 14) - multiplying by $Q$ and $Q^*$ are inverse change-of-basis operations. **Length and angle preservation** (p. 15, eq. 2.9-2.10): $(Qx)^*(Qy) = x^*Q^*Qy = x^*y$ directly from $Q^*Q=I$, so inner products - and therefore every length and angle built from them - are invariant under unitary multiplication. In the real case, multiplying by an orthogonal $Q$ is a rigid rotation if $\det Q = 1$, a reflection if $\det Q = -1$ (p. 15) - a cleaner, book-sourced statement of exactly what the lecture called "just rotations and flips."
> [!NOTE] One open point the lecture flagged, now resolved by the book
> The lecture's own proof left open whether angle-preservation holds for a *rectangular* (non-square) orthonormal $Q$, not just a full unitary one. The book's Theorem 3.1 (next lecture, p. 23) answers this directly: the 2-norm and Frobenius-norm invariance under unitary multiplication "remains valid if $Q$ is generalized to a rectangular matrix with orthonormal columns" - so the professor's uncertainty was well-placed caution, not an error, and the rectangular case does hold.
### Norm axioms and the $p$-norms (p. 17-18)
Three conditions (eq. 3.1): positivity, triangle inequality, absolute homogeneity. The $p$-norms (eq. 3.2): $\|x\|_1 = \sum|x_i|$, $\|x\|_2 = \sqrt{x^*x}$, $\|x\|_\infty = \max_i|x_i|$, and the general $\|x\|_p = (\sum|x_i|^p)^{1/p}$. *A concrete detail the lecture didn't have:* the book notes the 1-norm's unit ball is the shape airlines use to define maximum allowable suitcase size, and the 4-norm's unit ball is the shape of Sergels Torg plaza in Stockholm - popularized by the poet Piet Hein as a "superellipse" (p. 18). **Weighted norms** (eq. 3.3-3.4): $\|x\|_W = \|Wx\|$ for diagonal weight matrix $W$; the book allows $W$ to be any nonsingular matrix as a further generalization (Exercise 3.1), matching the lecture's own framing.
### Induced matrix norms (p. 18-19)
Defined via the supremum $\|A\|_{(m,n)} = \sup_{x\neq 0}\|Ax\|_{(m)}/\|x\|_{(n)}$, equivalently the supremum over the unit ball (eq. 3.5-3.6) - identical to the definition the lecture used for the recap that opens [[20_Progress/Degree/CSCI 5304/Textbook/Lecture - 4|Lecture 4]].
### Worked examples of matrix norms (p. 19-21)
*Example 3.1 (p. 19):* $A = \begin{bmatrix}1&2\\0&2\end{bmatrix}$ maps the unit balls of $\mathbb{R}^2$ to different shapes under the 1-, 2-, and $\infty$-norms; $\|A\|_1 = 4$ (amplified at $(0,1)^*$), $\|A\|_\infty = 3$ (amplified at $(1,1)^*$), $\|A\|_2 \approx 2.9208$ (amplified at a direction found via the SVD, deferred to Lecture 5). *Example 3.2:* for diagonal $D$, $\|D\|_p = \max_i|d_i|$ for any $p$ - the 2-norm case previews next lecture's hyperellipse picture exactly (image of the unit sphere under a diagonal map is an ellipse whose semiaxis lengths are the $|d_i|$). *Examples 3.3-3.4 (p. 20-21):* the proof the lecture gave for "matrix 1-norm = max column sum" is reproduced in the book almost identically - write $Ax$ as $\sum_j x_ja_j$, bound via the triangle inequality by $\max_j\|a_j\|_1$, then show $x=e_j$ (the column with largest norm) achieves the bound exactly (eq. 3.9). The $\infty$-norm case ($\max$ row sum, eq. 3.10) that the lecture explicitly flagged as "not proved in class" **is** proved in the book by the identical column-sum argument applied to rows - confirming it's a real, stated gap in the lecture capture, not an error, and the proof pattern transfers directly.
### Cauchy-Schwarz, Hölder, and bounding $\|AB\|$ (p. 21-22)
Hölder's inequality $|x^*y| \leq \|x\|_p\|y\|_q$ for $1/p+1/q=1$ (eq. 3.11); Cauchy-Schwarz is the $p=q=2$ case (eq. 3.12) - neither was mentioned in the lecture, a genuine textbook-only addition. *Example 3.5-3.6 (p. 21-22):* for a single row $A=a^*$, $\|A\|_2 = \|a\|_2$ exactly (via Cauchy-Schwarz, tight at $x=a$); for a rank-one outer product $A=uv^*$, $\|A\|_2 \leq \|u\|_2\|v\|_2$, tight at $x=v$ - this second fact is the textbook's own version of exactly the rank-one-matrix picture the Sep 29 lecture used when discussing low-rank approximation (see [[20_Progress/Degree/CSCI 5304/Textbook/Lecture - 5|Lecture 5]]'s updated Low-Rank Approximation section). Submultiplicativity $\|AB\|_{(\ell,n)} \leq \|A\|_{(\ell,m)}\|B\|_{(m,n)}$ (eq. 3.14) is not generally an equality - the book notes $\|A^n\| \leq \|A\|^n$ holds but not with equality in general.
### General matrix norms and the Frobenius norm (p. 22-23)
A matrix norm need only satisfy the three vector-norm conditions over the $mn$-dimensional space of matrices (eq. 3.15) - it need not be induced by a vector norm. The **Frobenius norm** $\|A\|_F = (\sum_{ij}|a_{ij}|^2)^{1/2}$ (eq. 3.16) is exactly the 2-norm of $A$ treated as an $mn$-vector; equivalently $\|A\|_F = \sqrt{\operatorname{tr}(A^*A)} = \sqrt{\operatorname{tr}(AA^*)}$ (eq. 3.18) - this trace identity is exactly the tool [[20_Progress/Degree/CSCI 5304/Textbook/Lecture - 5|Lecture 5]] uses to derive $\|A\|_F = \sqrt{\sum\sigma_i^2}$. The Frobenius norm also bounds products, via Cauchy-Schwarz applied entrywise (p. 23).
### Invariance under unitary multiplication (Theorem 3.1, p. 23)
$\|QA\|_2 = \|A\|_2$ and $\|QA\|_F = \|A\|_F$ for unitary $Q$ - proved by substituting into the sup-definition (2-norm) and the trace identity (Frobenius norm). This is the exact fact [[20_Progress/Degree/CSCI 5304/Textbook/Lecture - 5|Lecture 5]]'s existence proof leans on when it asserts $\|A\|_2 = \|U_1^*AV_1\|_2$.
## Worked Example
Take the "matrix 1-norm = max column sum" proof (Example 3.3, p. 20-21) as the fully worked example, since it's the one result both the lecture and book derive identically and it generalizes cleanly: write $A$ by columns, $Ax = \sum_j x_ja_j$; apply the triangle inequality and homogeneity to get $\|Ax\|_1 \leq \sum_j|x_j|\|a_j\|_1 \leq (\max_j\|a_j\|_1)\sum_j|x_j| = \max_j\|a_j\|_1$ for $x$ in the 1-norm unit ball; then choosing $x=e_j$ for the maximizing column $j$ achieves this bound exactly, so $\|A\|_1 = \max_j\|a_j\|_1$ (eq. 3.9). The same pattern, applied to rows instead of columns, proves the $\infty$-norm case the lecture didn't have time to finish.
