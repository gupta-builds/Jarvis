# How to Solve Problems
Read the contract, study the mapped idea, then write and explain the solution manually. A source mapping helps select an approach; it does not prove that the professor solved the exact interview question.
## Read the full contract
Read the linked official/captured statement, constraints, examples and mutation/output requirements. Record directedness, value ranges, duplicate rules and whether the output is a boolean, count, path, ordering or transformed structure. Read the assigned textbook/concept and relevant notebook methods before the attempt. Where CSCI coverage is adjacent, cite the CodePath or verified Handbook bridge explicitly.
## Use UMPIRE
1. Understand: restate input, output and constraints; identify ambiguities rather than repairing the problem from memory.
2. Match: name the data structure/pattern and exact source bundle; distinguish the task’s contract from a similar captured problem.
3. Plan: state the representation, invariant or DP state, progression and expected time/space bounds before coding.
4. Implement: the student writes manual code; existing source code may be studied, but copied or AI-generated code is not independent evidence.
5. Review: trace examples and relevant empty/singleton, duplicate, skewed/cyclic, negative-value or boundary cases; check required mutation and identity behavior.
6. Evaluate: justify time and auxiliary space using stated variables; include recursion depth and output size where applicable. Explain discrepancies from the plan.
## Time and assistance
Use the catalog’s attempt cap. On a block, record the exact failure and request a conceptual hint before a solution. An assisted result stays labeled assisted until a later unaided attempt succeeds. Do not count reviewing a captured in-class prompt as a new independent solve.
## Completion evidence
The ledger must record actual elapsed time, hint use, a working manual result or justified paper reasoning, edge cases and explained complexity. A later unaided recall attempt supplies retention evidence. The count of selected problems is not the count of independently completed problems.
## Source anchors and note record
Use the exact problem URL, [[20_Progress/Degree/_Courses/Technical Interview/CSCI 4041 Relation|source bundle]], notebook/PDF question number where relevant, and [[20_Progress/Degree/_Courses/Technical Interview/Problems Solver#Execution ledger|execution ledger]]. Keep the solution note in the existing Problems folder after a real attempt. When source syntax or examples are defective, record the defect and the checked contract without editing raw transcript files.
