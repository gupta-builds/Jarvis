# _Courses — Non-Degree Study Map
This folder holds every certification and self-study course running alongside the six credit-bearing Fall'26 classes in [[20_Progress/Degree/Fall'26 Syllabus|Fall'26 Syllabus]]. None of these earn UMN credit - they exist because [[10_Areas/Life/Plans/Fall 2026/Fall 2026 - The One Thing|Fall 2026 - The One Thing]] treats technical-interview strength and a real ML/cert portfolio as mandatory regardless of the internship push, not optional extras. This note is the sequencing map; each track now has its own deep-dive note (resources, real syllabus/outline, exam mechanics, and an honest goal-alignment call) linked from the Map below - read this note for how the tracks relate to each other, the per-course note for how to actually do the thing.

## Map
**GitHub Foundations** is first in the sequence and closest to done. The DataCamp prep course for it is already finished; a GitHub Student Developer Pack promo code is pending, and the exam gets registered and written the day that code arrives. This is the certification base the rest of the cert sequence sits on top of.

**AI Associate Engineer** is DataCamp's [[20_Progress/Degree/_Courses/AI Associate Engineer/AI Associate Engineer|AI Engineer for Developers Associate Certification]]. It starts right after GitHub Foundations closes out. This is **two exams**, not one - AIEDEVA101 (2hr timed knowledge exam) and AIEDEVA501P (4hr practical, three scenario tasks built around the OpenAI API) - inside the same 30-day window. Corrected 2026-09-08: the user's own certification progress screen read "29 days left, 0/2" as of that date, which puts the real deadline at **2026-10-07** (not the earlier estimate of 2026-09-30) and confirms **both** exams are required - the "0/2" settles what was previously an open question.

**ML Engineer** is now a merged track, decided by the user 2026-09-08: DataCamp's [[20_Progress/Degree/_Courses/ML Engineer/ML Engineer|Machine Learning Engineer career track]] (12 courses, ~44 hours) and DataTalksClub's MLOps Zoomcamp (6 modules + capstone) run **simultaneously, almost as one course**, not as two separate parallel tracks the way this board used to list them. The former "ML Ops" entry in this folder is retired - its content is folded into the `ML Engineer` note, which now also carries a module-to-module pairing between the two curricula. No live MLOps Zoomcamp cohort is planned for 2026, confirmed 2026-09-08, so its certificate isn't obtainable this year regardless - the actual deliverable was always the local repo both curricula get implemented into, not either provider's completion badge. That repo doesn't exist yet; naming and scaffolding it is the one open task blocking real progress on this track.

**Technical Interview** prep starts now, while GitHub Foundations and AI Associate Engineer are still running - it doesn't wait for either to finish. The course is CodePath's [[20_Progress/Degree/_Courses/Technical Interview/Technical Interview|TIP103]] - University Partnership Students edition, real syllabus captured in full 2026-09-07 (goals, prerequisites, 9 topic areas, grading, policy), and the actual cohort cadence confirmed by the user 2026-09-08: **12 weeks, Tuesday and Thursday 7-9pm, starting the week of 2026-09-14** - already on Google Calendar, though exact calendar dates beyond the start aren't fully nailed down. Important correction, also confirmed 2026-09-07: the vault's `20_Progress/Degree/CSCI 4041/` folder is **not** TIP103's material - it's a different, already-completed UMN class (Algorithms & Data Structures, Spring'26, grade A, `status: archived`). Cadence: LeetCode every day, plus these Tue/Thu sessions.

**System Design** and **Cloud Architect** are both explicitly deferred as of 2026-09-08 - the user's own words: "quite far away... right now we have a solid plan that needs to be executed correctly." No research or note work on either happens until GitHub Foundations, AI Associate Engineer, and the Technical Interview/ML Engineer combo are actually running well. [[20_Progress/Degree/_Courses/System Design/System Design|System Design]] has no fixed start date and runs via the System Design Primer once started. [[20_Progress/Degree/_Courses/Cloud Architect/Cloud Architect|Cloud Architect]] has a hard future start date of **2026-11-01** (a LinkedIn Learning free-trial month) and no curriculum chosen yet - the weeks until then go toward building the LinkedIn outreach process itself, not certification work.

CSCI 2033 lives in the Degree folder alongside these but isn't a Fall'26 class either - it's linear-algebra review material serving as helper prep for CSCI 5304 (Matrix Theory). GitHub Foundations doesn't get its own deep-dive note - the user assessed it as too basic to warrant one, already completed.
