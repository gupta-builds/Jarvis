# Applying
Private, ignore rule pending. Open this after screening a posting to see which notes the tier calls for.
## Tier 1 and tier 2
==Use a Program, a Contact, an Applying note and a submission Tracker.==
Create tier 2 Program and Contact notes beforehand, one at a time with `/promote-dossier`. A Program is required to apply. Contact research can continue while the application is ready.
## Tier 3
==Create just the Tracker when you submit.==
Keep the role in [[20_Progress/Internship/Applying/Apply Today|Apply Today]] while it is in flight.
## Ready to apply
==Check the posting, deadline, Screen result and document choices.==
The posting text is captured, its deadline has not lapsed, and Screen did not reject the role. Screen by eye. Set `resume_variant` and `letter_mode`. Check for a Program for tiers 1 and 2.
Follow the [[30_Order/Workflows/Internship/Internship Pipeline|Internship Pipeline]] and [[30_Order/Workflows/Internship/Application Document Preparation|Application Document Preparation]]. Use the [[20_Progress/Internship/Resumes/Resume Guide|Resume Guide]] and [[20_Progress/Internship/Cover Letters/Cover Letter Guide|Cover Letter Guide]] when preparing the files.
