# Cover Letter Guide
Private, ignore rule pending. Open this after choosing the tier to decide what letter to prepare for the posting.
## Tier 1
==Use `letter_mode: tailored`.==
Open with a sourced detail about the company. Use evidence from the Program, a linked project, or a fact Anant confirms to show how your work fits the role.
## Tier 2
==Use `letter_mode: bank` with one hook specific to the company when the bank is available.==
Use the posting and Program to choose the hook. Anant approves each letter before sending.
### Until the bank exists
==Use the posting’s letter requirement to decide what to do today.== If a letter is optional, apply without one. If it is required, write one tailored, evidence-based letter for that application and have Anant approve it before sending. Reusing wording from the technical example requires Anant’s review.
## Tier 3
==Use `letter_mode: none`.==
Check the application form for a letter requirement. Follow [[30_Order/Workflows/Internship/Application Document Preparation|Application Document Preparation]] when a letter is required. Anant approves every document that goes out.
## Examples and export
==Keep example and main letters directly in `Cover Letters/`, and export a working application letter to `Cover Letters/Altered/<Role> - <Company>.docx`.==
`Non Technical Cover letter.docx` and `Techincal Cover Letter.docx` are seeds for the fragment bank. Use them to discuss what belongs in the bank. The technical example is generic and may need updating. `Cover Letters/Altered/` and `Sent/` are private, ignore rule pending.
