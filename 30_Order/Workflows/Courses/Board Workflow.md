# Board Workflow
Use this when a course is first added, when the syllabus/modules page changes, or when a major schedule, grading, or source correction affects downstream notes.
## Steps
1. Read [[Board Standard]] and [[Board or Main Template]]. Search for an existing course Board before creating one.
2. Identify the live syllabus/Canvas source, local course source folder, textbook, schedule, instructor/staff, grading, assessment rules, and known uncertainties.
3. Fill the Board from authoritative sources. Separate verified facts, dated observations, inferences, and questions to confirm.
4. Reconcile grading counts/weights and map every assessment to the appropriate course workflow/template.
5. Link the Textbook Map, Weekly Board, Preparation note, source folder, active assignments/projects, and concept board only after checking that each exists.
6. Set `next` to the earliest concrete verification or note-production action.
7. When the Board changes, inspect affected weekly, exam, homework, project, and preparation notes for stale claims.
## Done when
- Current source authority and verification date are explicit.
- Schedule, grading, and policy details are reconciled rather than guessed.
- Unknowns remain visible and actionable.
- Downstream indexes and notes have real links.
