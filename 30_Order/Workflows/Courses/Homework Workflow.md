# Homework Workflow
Run a bounded individual deliverable from prompt to submission to reflection, leaving evidence at each step.
## Use when
Work is assigned that is not a multi-week project and not a discussion reading. For those, use [[Projects Workflow]] or [[Discussion Workflow]].
## Steps
1. Read [[Homework Standard]] and the prompt and rubric. Create the note from [[Homework Template]] as soon as the work is assigned.
2. Turn every deliverable, constraint, test, citation rule, collaboration rule, submission step, and secondary deadline into Requirements.
3. Link the scheduled week, textbook sections, concepts, and source files before solving.
4. Log attempts as they happen: approach, evidence, failure, diagnosis, fix, next step. Never reconstruct tests or errors from vague memory.
5. For coding work, separate written reasoning, implementation, tests, and any required TA or code review. For writing, track thesis, evidence, outline, citations, feedback, and revisions.
6. On submission, add the `### Submission` receipt to the work log, including code-review completion.
7. After feedback, write the post-submit reflection and carry reusable mistakes to the concept, preparation, and exam-review notes.
8. Run [[Vault Lint]] on the path and fix what it reports.
## Do not
Do not mark the work complete because a file exists, claim unseen test results, or submit work the student has not understood and reviewed.
## Done when
- Requirements and rules are complete and verified.
- The work log holds evidence and diagnosis.
- Submission, feedback, and reflection are recorded once they exist.
