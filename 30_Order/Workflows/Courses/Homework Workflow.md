# Homework Workflow
Use this for problem sets, written/coding homework, writing assignments, short quiz records, and other bounded individual deliverables that are not multi-week projects.
## Steps
1. Read [[Homework Standard]] and the prompt/rubric, then create the note from [[Homework Template]] as soon as the work is assigned.
2. Translate every deliverable, constraint, test, citation rule, collaboration rule, submission step, and secondary deadline into Requirements.
3. Link the scheduled week, textbook sections, concepts, examples, and source files before solving.
4. Record the work log as attempts happen: approach, evidence, failure, diagnosis, fix, and next step. Never reconstruct tests or errors from vague memory.
5. For coding work, separate written reasoning, implementation, tests, and any required TA/code review. For writing work, track thesis, evidence, outline, citations, feedback, and revision decisions.
6. Record the submission receipt and code-review completion. After feedback, write the post-submit reflection and propagate reusable mistakes to concept/exam/preparation notes.
## Routing
Use [[Project Workflow]] when choices, a shared scaffold, or a multi-week artifact make the work larger than a single bounded assignment. Use [[Discussion Workflow]] for participation/readings.
## Done when
- Requirements and rules are complete and verified.
- The work log contains evidence and diagnosis.
- Submission/feedback/reflection are recorded when applicable.
