# Preparation Workflow
Use this at course setup, after the first graded artifact, before major assessments, and whenever the course rules or schedule changes.
## Steps
1. Read [[Preparation Standard]], the course Board, schedule, and assessment notes.
2. Rank grading leverage using verified weights, frequency, difficulty, and secondary deadlines.
3. Build a recurring time budget for pre-reading, textbook note production, concept preparation, lecture capture, post-lecture reconciliation, assignments, discussion, and review. Label estimates.
4. Write habits as trigger -> action -> done condition. Include the different preparation modes required by open-resource and individual/limited-resource assessments.
5. Record course-specific traps and professor preferences with source/date and label inference.
6. Revisit after feedback or a recurring failure; change the habit or checklist that would have prevented it.
## Done when
- Priorities derive from real course rules, not generic study advice.
- Habits produce observable notes, practice, submissions, or verification.
- Uncertainty and estimated time are labeled.
