# Textbook Map Workflow
Use this when a course starts, the syllabus/modules schedule changes, a new textbook/source lands, or a chapter note is produced.
## Steps
1. Read [[Textbook Map Standard]], the Board schedule, and the course textbook/source inventory.
2. Record the textbook edition and every assigned chapter/section/module in chronological course order.
3. Link each entry to the correct path-qualified chapter note, matching week, and due/reading date when verified.
4. Mark each entry `not started`, `prepared`, `captured`, `reconciled`, or `needs review`. Add source-discovered sections separately from published assignments.
5. When a textbook note lands, update its entry and queue concept/weekly preparation. When lecture reveals a changed section, preserve the old mapping and record the correction.
6. Keep chapter content out of the map; it is an index/status ledger.
## Done when
- Assigned sections and gaps are visible.
- Every link resolves to the intended course note.
- The map tells the next agent what to read, create, or verify.
