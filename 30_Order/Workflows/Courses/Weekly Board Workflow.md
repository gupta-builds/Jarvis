# Weekly Board Workflow
Use this when a week is scheduled, a weekly note is created/updated, or the course's recent coverage needs an honest freshness check.
## Steps
1. Read [[Weekly Board Standard]] and locate the course's actual weekly folder or legacy flat layout.
2. Create one chronological map entry per expected week, including holidays, exams, split weeks, and weeks awaiting capture.
3. Link the real weekly note and write one sentence describing its teaching arc and connection to adjacent weeks.
4. Update status only from the week note's actual lifecycle: pre-lecture scaffold, live capture pending, captured, reconciled, or review-ready.
5. Identify the earliest incomplete week in `next`. Do not call the board current because empty stubs exist.
6. Verify the Dataview query against the actual course path and `input_kind: lecture`.
## Done when
- Every expected week appears once and links to a real note.
- Missing sources/capture/reconciliation are visible.
- The board remains an index, not a duplicate lecture note.
