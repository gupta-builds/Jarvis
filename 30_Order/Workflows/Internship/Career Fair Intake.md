# Career Fair Intake
Turn a recruiting event into captured sources, dossiers for real postings, and promoted notes for the ones worth pursuing.
## Use when
After a career fair, or when a batch of postings arrives from one event instead of the research loop.
## Steps
1. Before the fair, list the companies in the fair note, one line each with the posting status and a question to bring.
2. During and after, paste raw conversations and pages as separate capture notes under `Career Fair/`, untouched.
3. For each posting you heard about, write one dossier in `List/Dossiers/_Career Fair/` with `source: CareerFair-Manual`, the `career-fair` tag, and a specific `matched_reason`.
4. Screen each dossier and record `screened_decision` and `screened_reason`.
5. Promote the passes in one sitting: a Program in `Programs/Serious/Career Fair/`, a Contact in `Contacts/Each One/Ongoing/`, and a Tracker in `Current/`, all sharing one file name.
6. Add one line to the Main Log naming the event and the counts.
## Do not
Do not create the four notes from a blank template without the posting's facts. Do not promote a posting that never went through Screen.
## Done when
- Every posting heard about has a dossier or a recorded reason.
- Every pass has its Program, Contact, and Tracker, cross-linked and named alike.
