## Python Libraries

### pypdf - Basic Operations

#### Merge PDFs
```python
from pypdf import PdfWriter, PdfReader

writer = PdfWriter()
for pdf_file in ["doc1.pdf", "doc2.pdf", "doc3.pdf"]:
    reader = PdfReader(pdf_file)
    for page in reader.pages:
        writer.add_page(page)

with open("merged.pdf", "wb") as output:
    writer.write(output)
```

#### Split PDF
```python
reader = PdfReader("input.pdf")
for i, page in enumerate(reader.pages):
    writer = PdfWriter()
    writer.add_page(page)
    with open(f"page_{i+1}.pdf", "wb") as output:
        writer.write(output)
```

```python
reader = PdfReader("document.pdf")
meta = reader.metadata
print(f"Title: {meta.title}")

```

```python
reader = PdfReader("input.pdf")
writer = PdfWriter()
```

```python
import pandas as pd

with pdfplumber.open("document.pdf") as pdf:
```

#### Basic PDF Creation

#### Create PDF with Multiple Pages
```python
from reportlab.lib.pagesizes import letter
from reportlab.platypus import SimpleDocTemplate, Paragraph, Spacer, PageBreak
from reportlab.lib.styles import getSampleStyleSheet

doc = SimpleDocTemplate("report.pdf", pagesize=letter)
styles = getSampleStyleSheet()
story = []

# Add content
title = Paragraph("Report Title", styles['Title'])
story.append(title)
story.append(Spacer(1, 12))

body = Paragraph("This is the body of the report. " * 20, styles['Normal'])
story.append(body)
story.append(PageBreak())

# Page 2
story.append(Paragraph("Page 2", styles['Heading1']))
story.append(Paragraph("Content for page 2", styles['Normal']))

# Build PDF
doc.build(story)
```

#### Subscripts and Superscripts

**IMPORTANT**: Never use Unicode subscript/superscript characters (₀₁₂₃₄₅₆₇₈₉, ⁰¹²³⁴⁵⁶⁷⁸⁹) in ReportLab PDFs. The built-in fonts do not include these glyphs, causing them to render as solid black boxes.

Instead, use ReportLab's XML markup tags in Paragraph objects:
```python
from reportlab.platypus import Paragraph
from reportlab.lib.styles import getSampleStyleSheet

styles = getSampleStyleSheet()

# Subscripts: use <sub> tag
chemical = Paragraph("H<sub>2</sub>O", styles['Normal'])

# Superscripts: use <super> tag
squared = Paragraph("x<super>2</super> + y<super>2</super>", styles['Normal'])
```

For canvas-drawn text (not Paragraph objects), manually adjust font the size and position rather than using Unicode subscripts/superscripts.

```python

import pytesseract
from pdf2image import convert_from_path

images = convert_from_path('scanned.pdf')

text = ""
```

### Add Watermark
```python
from pypdf import PdfReader, PdfWriter

# Create watermark (or load existing)
watermark = PdfReader("watermark.pdf").pages[0]

# Apply to all pages
reader = PdfReader("document.pdf")
writer = PdfWriter()

for page in reader.pages:
    page.merge_page(watermark)
    writer.add_page(page)

with open("watermarked.pdf", "wb") as output:
    writer.write(output)
```

<pasted_content id="b282">
Justin Kittredge started ISlide, a slide company - in January 2013 from an office in Wellesley, Massachusetts. He made the customizable athletic sandals known as "slides" before starting the company, spending thirteen years in the footwear space — including four years selling and marketing Reebok shoes, two years as a product manager at Atsco Footwear, and then landing as the Director of Product Development for Performance Basketball at Reebok, where he field tested and designed the shoes worn by NBA players and managed factories in China. When Reebok laid him off in December 2012, he was under a noncompete agreement but had thirteen years of manufacturing relationships and product-development expertise. He used the layoff as an opportunity to test his own entrepreneurial instincts and fund the new company from personal savings. ISlide launched six months later.

I chose to highlight Kittredge's profile rather than one of the more famous entrepreneurs I considered (Sara Blakely or the founders of Airbnb) because his story challenges a premise that underlies everything I'm learning for this class, which is that if you want to found a tech startup, you should major in computer science. I am a computer science major, and this semester I've been building a portfolio site, a market-research tool, and an agentic automation pipeline — all with the goal of landing a software or AI engineering internship for next summer. These projects have convinced me that most would benefit from at least one founding team member having a computer science degree. But I assumed that would mean needing a singular genius to design some truly clever product nobody else could think of, and Kittredge's story is not that story. He did not have a product genius; he spent thirteen years in the footwear space developing the very specific and narrow expertise needed to launch a niche sandal company. That dovetails nicely into the main lesson of Chapter 2, which is that eighty percent of Inc. 500 founders started their companies in the same industry they were already working in.
