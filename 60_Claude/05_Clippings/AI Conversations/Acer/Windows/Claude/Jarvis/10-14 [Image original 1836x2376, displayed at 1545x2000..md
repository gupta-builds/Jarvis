## Q5 — Randomness in Local Search (6 points, 4–5 sentences)

**Final answer (exam-ready, 5 sentences):** Hill climbing can get stuck at a local optimum or a plateau, where every immediate neighbor is no better than (or strictly worse than) the current state, even though a better state exists elsewhere in the space. Introducing randomness — occasional worse moves, random restarts, or random sideways steps — lets the search escape that trap by occasionally moving somewhere a greedy algorithm never would. Simulated annealing formalizes this with a temperature schedule: early on (high temperature) it accepts "bad" moves relatively often via `random.random() < e^(ΔE/T)`, allowing broad exploration, and as temperature cools it accepts them less and less, settling toward improvement. In the 5-queens example from Q4b, plain steepest-ascent hill climbing is stuck at value 8 with no improving neighbor; a willingness to take one of the sideways/worse moves (e.g., accept a value-8 neighbor or briefly drop to 6) can route the search onto a path that later reaches value 10. This only improves the *chance* of success, not a guarantee — a finite annealing run can still terminate without finding the global optimum.

Sources: Discussion 5 pp.12–13 (explicitly cross-references Q4b's "8, then 6, then 10" trace); Lecture 08 slides 14–23 / Lecture 09 slides 3–6 (identical SA pseudocode and "annealing/temperature" metaphor, `e^(ΔE/T)` acceptance rule); textbook §4.1.1 Hill-climbing (PDF p.236–241, random-restart variant), Simulated annealing (PDF pp.242–243).
Verification: re-derived the acceptance-probability argument directly from the lecture's own pseudocode rather than copying Discussion 5's prose; conclusion matches.

## Reusable mistakes these questions test
1. **Reward timing**: whether you count performance *before* or *after* the action flips the vacuum score by exactly the cost of one action — always state the convention.
2. **"Lowest possible" vs "expected"**: lowest possible picks the adversarial random outcome (all slips fail); expected value would be much higher since movement succeeds 80% of the time.
3. **Fewest actions ≠ cheapest path**: IDDFS/BFS optimize action count; UCS/A* optimize total cost — these diverge whenever costs are unequal.
4. **Admissible ≠ consistent**: admissible only bounds `h` against the *global* cheapest remaining cost; consistent requires the *local* triangle inequality on every edge.
5. **Scaling a valid heuristic breaks admissibility**: `2×misplaced-tiles` and `max(...)` of a non-admissible component both inherit the overestimate.
6. **Strict-improvement hill climbing ≠ allows sideways moves**: a 7-way tie for "best neighbor" at the same value as current still means "no improving successor," so steepest-ascent (without sideways-move permission) halts.

    return sorted(edges[n], key=lambda x: x[0])

def bfs():
    from collections import deque
    frontier = deque([('A',0)])
    reached = {'A'}
    explored = []
    while frontier:
        n,g = frontier.popleft()
        explored.append(n)
        if n in goals:
            return explored, g
        for c,cost in children(n):
            if c not in reached:
                reached.add(c)
                frontier.append((c, g+cost))
