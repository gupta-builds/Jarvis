## MUX switch: what it is and whether you need it

Your laptop has **Advanced Optimus**, which is a MUX switch that can route the display either through the integrated Intel GPU (power-saving, dynamic switching) or with a **direct physical connection to the RTX 5070 Ti** (max performance, enables G-Sync).

- **PredatorSense → Personal Settings → GPU Operating Mode**, three options typically: *Auto/Optimus* (dynamic switching, best battery life), *Hybrid*, and *NVIDIA GPU Only / Discrete* (MUX engaged, max performance + G-Sync, costs battery).
- **Do you need it?** For your stated use (AI dev work, classes) — leave it on **Auto/Optimus** day-to-day; that's what saves battery when you're just coding/writing. Switch to **Discrete/NVIDIA GPU Only** only when doing GPU-heavy local AI workloads (fine-tuning, local LLM inference, Stable Diffusion, gaming) where you want the dGPU driving the display directly.
- **Given the known freeze bug on this exact SKU** (see above), if you ever see the screen lock up or go black while switching modes: don't panic, wait to see if it clears in a few seconds, and if it doesn't, hold power to hard-reboot. If it recurs, either stick to one mode (don't toggle back and forth) or pursue the community/Acer support thread linked above.

Source: [Acer Community — GPU Operating Mode / MUX guidance](https://community.acer.com/en/discussion/695904/[REDACTED])
